# GOAL.md — template

Copy into the project root and adapt. Everything below `---DIVIDER---` is the
instruction set the run executes.

```markdown
# Company Builder — Master Goal

---DIVIDER---

## Mission
Build a complete, sellable company from scratch, starting from the open
internet. Find a real, painful, underserved problem real people complain about
right now, design a business around it, build the product, brand and website,
and hand over a finished package that could go to market this month. Then prove
why it would work. Rank every call by expected revenue in 30 days against a
named, reachable buyer.

## Guardrails
- No new spending.
- Anything in this project's `.env` is fair game (state what keys exist).
- Publish nothing — everything local — unless I explicitly authorize a deploy.
- Invent nothing — research and verify every fact and stat; mark anything
  unverified as an assumption.
- Work only inside this project directory.
- Never fabricate credentials or data. Never pull live secrets into chat.
- Never pause for confirmation except where real-world spend, deployment, or
  credentials are required (those are mine to authorize).

## Founder edge (bias the hunt toward reachable buyers)
<Describe the operator's role, expertise, distribution channels, existing
ICPs and adjacent products. Prefer a problem reachable through those channels
so time-to-cash is short. Note any brand family or cross-sell to exploit.>

## Orchestration
Use multi-agent workflows aggressively: parallel researchers across angles, a
scored idea tournament with advocate + skeptic agents, adversarial red-team
verification of the winner, a completeness pass before packaging. The patterns
are a floor, not a ceiling.

## Arc
Hunt pain → tournament → pick winner → verify the anchor fact → red team →
name + brand (with real trademark clearance + domain checks) → build the
working product/site MVP → launch + founder video scripts → package the recap.
Then, on request, productize into a deployed secure platform (P0→P3). A floor,
not a ceiling.

## Definition of Done
A stranger opens `recap.html` and can understand the business, read the plan,
run the site/demo, and follow the decision record. Every headline stat is
sourced. The name is trademark-screened (not legal advice) with an acquirable
domain. There is a clear, sellable first offer with a named buyer.
```

## Notes
- Keep the phrasings that do the work: "invent nothing", "verify every fact",
  "ranked by expected revenue in 30 days", "a floor, not a ceiling".
- If a video/voice/image key is absent, the run ships scripts + storyboards, not
  rendered media — that is honest, not a shortfall to hide.
